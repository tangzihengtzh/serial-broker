# Serial Broker V2.0.0 Implementation Plan

> 用户要求与SSH V2一致；保留旧目录，在SerialBroker.V2开发，使用隔离模拟传输做功能验证，不访问真实COM设备，不进行额外渗透或压力测试。2026-10-27本地验收阶段曾要求暂不发布，随后用户明确指示“作为main,V2.0.0上传github吧”，现按该授权执行。本文记录开发清单与发布策略，远端执行结果以GitHub main、标签及Release为准。

**Goal:** 发布可同时管理多个物理串口、具有ModernWpf工作区和托盘生命周期的Serial Broker V2.0.0。

**Architecture:** 保留C++20 Broker、serialctl和原有SB管道协议，为Broker增加实例化C ABI动态库。新的.NET 8/ModernWpf前端为每个标签持有独立Broker实例及监视队列，管理历史、端口建议、主题和窗口持久化。生产版只打开COM设备，单独测试构建支持命名管道模拟串口；不把模拟入口作为GUI连接选项。

**Tech Stack:** C++20/MSVC/CMake、C ABI/PInvoke、.NET 8/WPF/ModernWpfUI 0.9.6、WinForms NotifyIcon、Python/Pillow生成原生矢量图标资源。

## 需求映射

- 多串口标签页，独立配置、写入策略、客户端、日志、RX/TX计数及故障状态。
- 欢迎页、顶部新建、可编辑串口下拉框（当前设备+历史）、备注可重名并支持表情。
- 保存波特率、Telnet开关/端口、DTR/RTS和日志根目录；不自动恢复活动连接。
- 新COM从7000起避开历史/草稿及系统占用端口；选择历史回填旧端口，允许手动覆盖。
- 四种全局主题：明亮、暗色、暖色、淡蓝；监视区同步；窗口位置/大小/最大化持久化。
- 新图标，关闭/Alt+F4隐藏到托盘；显式退出才释放全部连接。
- 帮助单独成文，不在UI嵌入MobaXterm/管道等教学文字；日志目录提供打开按钮。
- V2.0.0双语README、CHANGELOG、可运行包、版本元数据；按发布授权让main跟随最新、以V1.0.0归档旧版。
