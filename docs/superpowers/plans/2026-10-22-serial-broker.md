# Serial Broker Implementation Plan

> **For agentic workers:** 本轮在当前会话按任务逐项实现；用户已授权实现到编译结束。禁止动态验证，不启动目标程序，不访问物理串口，不安装驱动。

**Goal:** 创建 Windows 串口代理，让 MobaXterm 与 Agent 同时观察串口，并通过显式策略控制写入。

**Architecture:** 一个 Win32 桌面进程独占物理串口，后台接收线程广播到监视窗口、日志、Telnet 会话和命名管道会话。所有客户端写入进入同一有界队列，由单独线程按顺序发送；权限在入队和发送前分别检查。

**Tech Stack:** C++20、Win32、Winsock2、命名管道、MSVC 2022、CMake；不依赖第三方库。

## Task 2: 传输和协议

- [x] 用固定 8 字节头（magic、type、uint32 length，小端）定义有界消息。
- [x] 用 RAII 封装 Win32 句柄，实现带停止检测和超时取消的重叠读写。
- [x] 实现每会话独立发送队列和接收/发送线程；慢客户端只影响自身。
- [x] 实现 Telnet IAC 过滤、协商拒绝与输出 IAC 转义，保留普通串口字节。

## Task 3: 代理核心

- [x] 独占打开 COM，配置 8N1、无流控及显式 DTR/RTS 选项。
- [x] 绑定回环 TCP，提供当前用户限定的命名管道。
- [x] 默认共享写入（按用户后续要求调整）；下拉框控制只读/单写入者/共享，单写入者可首个发送或显式申请取得写入权，不设置授权按钮。
- [x] 所有写入按块排队、发送前复核授权；队列溢出拒绝，串口断开停止代理。
- [x] 接收/发送原始字节分别记录，附带带时间戳的事件日志。
- [x] 实现有界历史回放、状态快照、退出时取消 I/O 和线程回收。

## Task 4: GUI 与 CLI

- [x] GUI 提供串口枚举、串口参数、监听端口、日志路径、开始/停止和写入策略下拉框；移除会话授权按钮并修正下拉选择被刷新覆盖。
