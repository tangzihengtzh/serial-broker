## 本轮验证边界

按用户要求，验证到 **编译、链接和静态审阅** 为止。没有运行 `SerialBroker.exe`、`serialctl.exe`、单元测试程序或串口模拟器；没有打开物理 COM、建立代理监听、安装虚拟 COM 驱动、弹出 GUI 做界面检查或修改系统配置。

CMake 的编译器识别/ABI 探测只执行编译链接；本项目没有添加运行目标程序的 custom command、try_run、CTest 或 post-build 步骤。

## 静态审阅覆盖

- 串口独占句柄、DCB 8N1/无流控、可配置 DTR/RTS 与参数范围。
- 同步/挂起 I/O 的完成分支、超时取消竞态、缓冲区与 OVERLAPPED 生命周期。
- 默认共享写入、下拉框只读/单写入者选择、首个发送者自动取得写入权、断开时释放租约、排队请求 generation 复核。
- 客户端与 GUI 的队列上限、慢接收端断开、线程回收和退出取消。
- 回环监听、当前用户命名管道 DACL、拒绝远程管道客户端。
- Telnet IAC 输入过滤/输出转义、基础协商、CR NUL 处理。
- 日志偏移、容量限制、磁盘错误提示及失败块可能部分发送的语义。
- CLI 在发送前检查输入、发送确认/拒绝匹配、超时退出、Ctrl+C 和非预期断开返回码。
