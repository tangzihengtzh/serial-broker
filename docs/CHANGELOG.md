# Changelog

## 2.0.1 — 2026-11-10

- 顶部“设置”菜单增加可勾选的“开机自启动到托盘”，使用当前用户Windows Run启动项，无需管理员；取消勾选移除启动项。启动项包含实际程序路径及当前数据目录，登录后仅显示托盘，手动启动仍显示窗口。
- 自启动状态以实际注册表为准，读写失败提示错误并恢复真实勾选状态；托盘启动后直接退出不会以无效几何覆盖原窗口布局。
- “设置”下拉菜单统一提供“开机自启动到托盘”和“清除历史连接”；历史为空时禁用清除选项，确认框显示条数，默认取消。
- 确认后立即持久化并刷新所有标签的历史候选；保留系统当前串口、当前标签的设备名称和配置、活动连接、监视内容及设备日志。再次连接可重新记录配置。
- 保存失败恢复原内存历史，保留磁盘历史并显示错误；主题保存、退出及重启不会恢复已清除记录。
- 增加实际WPF菜单、模拟串口持续转发、重启、保存失败及隔离注册表自启动回归测试。

## 2.0.0 — 2026-10-27

- 新增ModernWpf多串口工作区；每个标签拥有独立的C++ Broker实例、Telnet端点、兼容命名管道、写入策略、客户端列表、计数和日志。
- 新增C ABI原生桥接库，由.NET 8前端管理实例生命周期；保留原C++20重叠I/O、TX串行队列、广播和SB管道协议，不引入虚拟COM驱动。
- 增加欢迎页、新建/关闭设备标签；关闭单个标签不会停止其它设备。
- 串口下拉框通过Windows SetupAPI读取设备管理器友好名称，如 `USB-SERIAL CH340 (COM4)`；选中项和下拉候选均保留完整名称，长名称提供换行显示和提示。实际连接、管道和历史身份继续使用规范化COM号，保留手动输入。
- 历史保存设备友好名称、连接配置和用户备注；设备离线时保留名称并标明历史未连接，在场设备名称优先于旧缓存。兼容旧版不含设备名称的历史数据；每个COM保留最近配置，最多200项，备注允许重名和表情。
- 打包脚本支持 `-OutputDirectory`，可将构建或发布包输出到独立目录，不覆盖运行中的程序。
- Telnet端口建议从7000起避开历史、标签草稿与系统监听端口；历史端口不强制锁定，用户手动编辑优先。
- 增加明亮/暗色/暖色/淡蓝全局主题、窗口位置/大小/最大化状态持久化及打开日志目录按钮。
- 增加串口连接器图标和托盘；关闭/Alt+F4仅隐藏，显式退出等待所有原生I/O和回调结束。
- 使用帮助独立成文，提供本地HTML帮助入口；移除旧主界面的终端和管道教学性状态文字。
- 监视显示支持暂停、清空和HEX；监视队列及历史有界，显示控制不影响原始转发/日志。
- `serialctl`增加 `--version`，原CLI用法、默认COM3、帧格式和退出码保持兼容；GUI/原生DLL/CLI版本统一2.0.0。
- 新增独立测试构建的命名管道模拟设备；生产库拒绝该传输入口。67项功能检查和3项生产包检查通过，没有打开真实COM。友好名称枚举另与本机当前设备信息核对；CH340/CP210x使用测试元数据验证显示与映射。
- 新GUI依赖.NET 8 Desktop Runtime（Windows x64）；原生组件仍使用静态MSVC运行库。发布包须完整保留DLL和JSON。
- 旧Win32单设备界面源码保留并可构建为 `SerialBroker.Legacy.exe`，不放入V2桌面运行包。
- 维护者授权作为main及V2.0.0发布，附完整Windows x64运行包和SHA-256校验文件。旧main归档为V1.0.0，不改写旧版源码或历史；发布说明见 `RELEASE-V2.0.0.md`。
